## Bugs found by the tests and fixed
* Draft save queue could stall permanently when a save cycle completed synchronously (promise reset race) —
  edits stayed local. Fixed (`project-context.service.ts`) and covered by the gate journey.
* Concurrent project open from shell + landing caused duplicate loads — now de-duplicated.
* Routed workspace hosts did not fill the viewport (encapsulated selector) — fixed globally.
